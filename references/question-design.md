# 问题设计方法论（question-design.md）

输入：简历分析结果（analysis-framework 输出）+ 岗位画像 + HR面模式选择。
输出：业务面问题清单（教学型问题卡）、HR面问题清单（按所选模式）、两场面试各 30 分钟时间分配表。

## 覆盖维度（业务面+HR面共同覆盖）

职业动机发展路径 / 简历真实性与能力边界 / 稳定性与工作安排 / 薪酬期待 / 行业认知 / 岗位职责了解 / 自我认知

## 一、业务面问题清单（8-10 题）——教学型问题卡（简历驱动定制）

> **第一性原则：面试是预测，不是审计**。30 分钟要最大化对「入职后能否做好、愿不愿做好、能否长久」的预测信息量。核实只解决"简历是假的吗"，不解决"他到底多强、合不合"。**优势深挖自带核验功能**——真做过的人自然讲得出颗粒度，拷问姿态换来的只是面试官的心理确认感，代价是候选人进入防御的应试模式，看到的不再是他的工作模式。结构化核验（学历/流水/履历逐段）归 HR 面与背调；业务面只保留与能力直接相关的口径问题，以好奇而非审判的姿态。

### 生成逻辑（五步，全部针对该人选的经历与岗位，非通用题库）

1. **简历钩子提取**：从简历提取可提问素材——
   - 高光素材（最自豪的项目/成就、被认可证据：晋升/加薪/获奖/被挖）
   - 关键项目/量化成果（含量化数字的条目）
   - 角色与晋升变化（转岗、晋升、职责跃迁）
   - 时间线信号（空档、频繁跳槽、超长任职）
   - 技能/证书声明（可验证性）
   - 自我评价与经历之间的张力点（自评高 vs 证据弱）
2. **题源三源制（按信息价值排序）**：
   - **岗位成功要素**（`success_factors` 2-3 条 / 画像核心职责 → 这个岗位上做好的人长什么样）→ 高光/能力深挖 4-5 题。**不得把 JD 原文改写后当问题**（「请讲讲你怎么做用户增长」这类泛题即违规）；成功要素是筛选器，问题是拿它去比对候选人具体经历后的产物。
   - **前瞻与情境**（把岗位真实场景给他现场处理——比挖过去更能预测未来）→ 1-2 题
   - **待考察点**（疑点验证 + 缺口题）→ 风险验证 1-2 题、缺口 1 题
   配比为参考值，因简历而异，为凑配额出题视为违规。原则：**先看上限（他最强处长什么样），再测匹配（这份具体的工作他愿不愿），最后验下限（疑点是真是假）**——不是下限不重要，而是下限可以外包给背调和 HR 面，上限不能。
3. **钩子 × 画像 × 待考察点 映射（一主两副）**：
   - 岗位画像的核心职责 → 选简历中最相关的钩子（岗位要跨部门协作 → 选简历中的跨部门项目）
   - 待考察点 → 疑点放在第三段验证；数字口径类核验并入高光深挖的追问，不单独立卡
   - **一主两副**：每题定 1 个主维度（决定高分锚定）+ 最多 2 个副维度（决定追问分叉方向）。主维度不得跨题重复；副维度允许复用。
4. **缺口题通道**：匹配度判"缺口"的维度（简历完全没提的能力）**强制配 1 题**，且只问边界迁移，不问"你做过吗"——问法：「这块你没碰过，交给你先动哪一步？」（测学习路径与资源借力，不逼人认短）。
5. **定制问题设计**：把简历具体内容**嵌进问题**（行为性问题，引用真实项目/数据/经历），再配教学单元。

### 主问题写法约束

- **铺垫句与问句分离**：背景铺垫 ≤2 句 + 单个问句；问句只含一个问号。
- **字数分层**：行为题（聊经历）简洁为主，总长 ≤60 字软约束；**情境模拟题按「场景参数 + 任务 + 约束 + 产出要求」构造，可到 80-120 字**——情境题的信息量就是预测效度，不为字数砍参数（无参数的情境题只能换来泛泛表态）。**英文产物对应 35 words / 60-90 words**，句式与禁用词见 `en-localization.md` 第四节。
- **专业度规则**：用行业语境与具体参数说话（决策链、预算口、pipeline、分润机制）。**打开型 ≠ 闲聊，好奇姿态 ≠ 口语化**：禁止哄人腔（「里面一定有你最自豪的」「你自己挑一单讲讲」）、水词（「顺便好奇下」「怎么看」万能收尾）；专业面试官的语言是简洁、具体、有语境。
- **题干不带判定立场**：禁止"到底哪个是真的""你为什么这么短"式预设质疑——用中性框架进入（「请完整讲一下这段经历」），把质疑留给追问。
- **姿态规则**：以**打开型**为主（「请完整讲讲这个项目从线索到回款的过程」「请讲讲你第一季度的开拓计划」——让人展现上限）；验证型问题用**好奇姿态**包装（「这单的签约口径是合同额还是回款额？」），禁止连环审判式提问。先聊他最强的，再碰存疑的。

### 每题结构（教学单元，6 要素）

- **主问题**：行为性提问，铺垫+单问句形态，内容引用候选人简历中的具体经历/数据。
- **考察维度**：一主两副（主维度定锚定，副维度定追问分叉），写明。
- **设计原理**：为什么这个问题能验证该维度（含简历验证逻辑，如"数据是简历最易注水处，对口径判断真实含金量"）。
- **高分锚定**：优秀回答的"听点"清单（3-5 条），**双轴**——
  - **强度轴**（做得好不好）：方法论能讲成打法而非个案；成功要素可复述、可迁移；讲得出取舍与备选方案；有从失败到迭代的痕迹
  - **真伪轴**（是不是真做过）：时间能落到年月 / 相关人能说出角色 / 数字能拆出构成（金额或指标基线）/ 能讲出卡壳环节与阻力 / 关键节点有"我"的决策
  锚定是帮面试官**听懂好坏的耳朵**，不是考核面试官的考卷——**红线：不出现分值/权重/评级，不做成打分卡**。
- **红旗信号**：对称的低分听点（3-4 条）：只有总数没有构成 / 时间全是模糊区间 / 关键节点全是"我们"没有"我" / 一路顺遂没有阻力 / 打法因人而异无法复制。
- **追问路径**：3-4 条追问话术，**每条带追问技巧标签**——让面试官在追问中学到方法论。**追问为弹性资源**：主问题必问，追问按需选取（回答已清晰则可不追问或只问 1-2 条），面试官根据现场情况灵活使用，不要求全部问完。技巧标签库（正向 2 + 验证 7 + 结构 2）：

| 技巧标签 | 用途 | 触发信号（听到什么用它） | 停止条件（追到什么算够） |
|---|---|---|---|
| 亮点深挖 | 听到真亮点往深处问，看方法论成型度 | 讲到做得漂亮的地方（正问姿态："这步怎么想到的？"） | 成功要素能拆成可复制的打法 |
| 情境模拟 | 把岗位真实场景给他现场处理（场景参数+约束+产出要求） | 需要预测未来表现时（比挖过去更准） | 给出具体打法与数字拆解而非原则表态 |
| SMART 校验 | 目标/结果是否具体可衡量 | 说到目标、KPI、期望值但没拆解 | 目标的时间/数值/构成三项都落了地 |
| 对口径 | 数字口径：范围、时间、含税/回款、个人还是团队 | 抛出业绩数字、百分比（好奇姿态） | 口径四要素（范围/时间/口径/归属）说清 |
| 漏斗追问 | 把过程拆环节追问转化 | 讲结果不讲过程（"最后签下来了"） | 关键环节的动作与转化都有数 |
| STAR 补问 | 追问 Situation/Task/Action/Result 缺失环节 | 故事缺背景、任务或动作环节 | 四要素齐、无跳跃 |
| 对抗验证 | 给出反例或质疑，看能否自圆其说 | 说法太顺、太完美 | 能接住质疑并给出合理解释 |
| 时间线验证 | 按时间顺序重走一遍，抓空档与矛盾 | 履历有多段、时间密集或含糊 | 各段起止与衔接能对上简历 |
| 假设法 | 换条件（资源减半/换市场），看应变 | 需测迁移能力或方法论真伪 | 给出可执行的新打法而非空话 |
| 反例法 | 让他举失败/最差案例，看归因 | 只讲成功案例、归因全在己 | 有真实失败案例且归因含自省 |
| 递进追问 | 连问"然后呢/为什么"，压出真实细节 | 回答停在概括层 | 细节落到具体的人和事 |

**标签使用要求**：一套题内标签尽量全覆盖（11 个中 ≥9 个）；单个标签占比 ≤25%（防单一套路）；正向标签（亮点深挖/情境模拟）与验证标签搭配使用——深挖高光本身就是核验。

### 提问顺序（四段）

1. **优势展开**：从他最强、最自豪的经历聊起（打开型开场，看上限；深挖高光自带颗粒度核验）
2. **情境前瞻**：把岗位真实场景交给他现场处理（测迁移与匹配，比挖过去更能预测未来；缺口题在本段）
3. **验证风险**：疑点（短段/空档/薪酬落差）在此段用**中性框架**进入，质疑留给追问；数字口径类核验多已在第 1-2 段的深挖中自然完成
4. **动机与吸引**：规划、适配、预期；**收尾是双向的**——除了问清楚他，也留出"这个岗位能给他什么"的呈现空间（好人选在挑雇主，收尾体验直接影响接 offer 意愿）

### 题组分配建议（按画像自适应）

| 画像信号 | 题组侧重 |
|---|---|
| 核心职责=结果指标交付 | 最好一单怎么打的（高光深挖）、开局情境、结果拆解 |
| 核心职责=专业深度输出 | 最自豪的方案/作品深挖、技术决策取舍、情境演练 |
| 核心职责=跨部门协作/影响力 | 最难推动的一件事、冲突处理打法、借力方式 |
| 核心职责=团队建设与管理（管理岗） | 带人案例、目标拆解、梯队培养、授权 |
| 待考察点含数据注水/贡献边界 | 并入高光深挖的追问（对口径），不单独立卡 |
| 待考察点含频繁跳槽/稳定性 | 风险验证段 1 题（中性框架） |
| 行业跨度大 / 人群场景迁移（如研发转销售团队） | 迁移情境题、对目标人群的预判、行业认知深度 |
| 外包/驻场经历 | 项目归属、个人贡献边界、交付物举证 |
| 硬技能达标存疑 / "精通"档自评 | 完整案例+细节追问（让候选人具体描述做法与决策） |
| 匹配度判"缺口"的维度 | 缺口题（只问边界迁移，不问"做过吗"） |

### 示例（教学卡·打开型形态）

候选人：电商运营专家，简历含「主导双11 GMV 1.2亿→1.7亿、+42%」；岗位核心职责=结果指标交付；待考察点=数据真实性/贡献边界。

- **主问题**：双 11 那次 GMV 同比 +42%。请完整讲一下这个项目：你的方案是怎么设计的，哪几个动作对结果贡献最大？
- **考察维度**：主=能力上限与打法成型度；副=结果口径真实性、复盘质量
- **设计原理**：从高光进入而非从疑点进入——真做过的人讲全过程时颗粒度自然出来（时间/人/决策点），核验在深挖中完成；同时能看到他的上限和打法是否可复制
- **高分锚定**：打法能拆成可复制的步骤；增长构成拆得出（哪月哪个品、个人和团队的边界）；对大盘自然增长有诚实说明；讲得出差点翻车的环节
- **红旗信号**：只有总数没有构成；把平台增长全算自己；打法讲不出步骤只有"拼"；没有惊险时刻
- **追问路径**：
  - [亮点深挖]「贡献最大的那个动作是怎么想到的？当时还有哪些选项？」
  - [对口径]「这 42% 的统计口径是什么？含税吗？覆盖哪个时间段？」
  - [情境模拟]「如果给你我们的店铺：客单价 300 元、大促预算减半、履约只能次日达——你的打法哪三步不变？」
  - [反例法]「讲一次你没做好的大促，复盘原因？」

### 生成后自检（覆盖矩阵 + 执行语义）

出完全部题后过一遍清单，违规项定位重做；**不在生成时按指标填空**。为达标而机械凑结构（强行拆分自然问题、堆砌未使用的标签、为配额凑题）视为不通过：

- 主维度不跨题重复，副维度 ≤2/题
- 画像点选维度与 8-10 题对照：选中但 0 覆盖的维度必须补题或写明"本轮不覆盖及原因"
- 匹配度判"缺口"的维度 ≥1 题缺口题
- 标签 ≥9/11 覆盖，单标签占比 ≤25%，正向标签（亮点深挖/情境模拟）至少各 1 次
- **姿态检查**：打开型/前瞻型主问题 ≥60%；纯核验型主问题（对口径/时间线/贡献切割类）≤2 题；通读一遍无连环审判感（连续 3 题以上都在"求证据"即为违规）
- **专业度检查**：情境题含 ≥2 个具体场景参数与明确产出要求；无哄人腔/水词；主问题读出来像资深面试官说的话，不像聊天
- 红线题在第三段（验证风险）、中性框架进入；数字口径核验已并入第 1-2 段深挖或 HR 面
- 高分锚定双轴齐备（强度轴 + 真伪轴），且无分值/评级形态

## 二、HR面问题清单：双模式（入口处点选选择）

### 模式 A：结构化模板（固化的四段清单，1:1 收录）

**一、身份与诚信（防造假 + 防扯皮）**
- 学历：是否全日制？毕业院校？毕业时间？学信网是否可查？（⚠️ 海外场景不问毕业时间与「全日制」，改由背调核验学历）
- 履历：简历所有工作履历逐段确认，确定有无空档（空档期追问去向；涉及家庭/婚育缘由不追问，转为工作安排可问项）
- **按职能补充**：
  - 技术/研发岗：竞业限制协议是否有效？上家项目的成果归属与知识产权约定？可展示的作品/代码是否涉密？
  - 职能支持岗（HR/财务/法务等）：离职证明是否齐备？是否负保密义务或竞业限制？有无未结的劳动纠纷关联？
  - 外包/驻场背景：与哪家人力主体签劳动合同？项目归属与可证明的交付物是什么？

**二、薪资与流水（防薪资造假）**
- 薪资构成：现月固定税前多少？补助如何？社保公积金按什么标准？税后每月到手一般是多少？（⚠️ 海外只问期望与构成 base/bonus/equity，不问历史薪酬，且无社保公积金口径）
- 奖金：奖金如何计算？年终奖是固定几薪还是浮动？

**三、岗位匹配（按职能配骨架；通用匹配四维兜底）**
- 销售三要素（仅销售岗）：
  - 区域：负责区域？市场容量？年销售额？
  - 产品：卖什么产品？客单价？销售模式（直销/渠道）？
  - 任务考核：过去三年每年任务数及完成率？考核维度有哪些？举一个最好和最差年份的具体情况。
- 技术/产品岗三要素：
  - 项目角色：负责哪个模块？个人交付物是什么？关键的技术/产品决策有哪些是你做的？
  - 交付与质量：上线规模（用户量/QPS/客户数）？质量指标（故障率/性能/返工率）？最好与最差的项目各是什么情况？
  - 技术栈与协作：核心技术栈熟练度到哪个层级？与上下游（产品/测试/客户）的协作界面在哪？
- 职能支持岗三要素（HR/财务/法务等）：
  - 服务对象与规模：支持哪类人群/多大体量？业务处于什么阶段？汇报关系与业务方是谁？
  - 专业模块覆盖：哪些模块是你主导的、哪些是配合的？各模块的代表性成果与口径？
  - 任务考核：历年绩效结果与团队排名？年度重点任务完成度？举一个最好和最差年份的具体情况。
- 绩效（全职能通用）：公司组织架构及部门定位？汇报关系？部门考核方式？个人历年绩效结果及团队排名？
- 通用匹配（兜底四维）：对这个岗位的理解？最匹配的经验是哪段？如果入职，前三个月最想解决什么问题？（与职能三要素组合使用，不重复出题）

**四、动机与风险（防稳定性问题）**
- 离职原因：历次离职的主要原因？是否被动离职？
- 稳定性：选择新工作时最看重的三个因素（按重要性排序）？我们这份工作在这三点上分别能打几分（1-10 分）？
- 薪资期望：期望年薪（税前全包）是多少？这个数字怎么算出来的？

**模板模式规则**：
1. 问题结构严格遵循四段清单，**每段具体措辞围绕简历定制**：学历段直接指向简历中的院校/时间；履历段指向简历空档；销售三要素指向简历中的销售经历。
2. 「岗位匹配」段按岗位画像自动切换：职能=业务增长类且具销售属性 → 销售三要素+绩效；产品技术类 → 技术/产品三要素+绩效；职能支持类 → 职能支持三要素+绩效；其余 → 通用匹配四维。骨架按职能配置，**具体措辞围绕简历定制**，不为凑骨架出重复题。
3. 每段标注一行**目的**（如：防学历造假 / 防薪资注水 / 验证任务真实性 / 识别稳定性风险），便于 HR 理解为什么问。
4. HR 后续提供的模板私有定制：写入本文件（或 skill 内模板文件）后直接沿用。
5. **合规红线**：不得出现询问婚育/家庭情况的问题（《妇女权益保障法》明确禁止）。稳定性类考察一律转为**与工作安排相关**的可问项，例如：「该岗位每月约 X 天出差，你的时间安排能覆盖吗？」「未来 2-3 年职业规划重心在哪？有没有会影响稳定出勤的安排需要提前同步？」
6. **海外岗位不套用本模板的中文措辞**：四段改为 `en-localization.md` 第五节的重构版（Work Authorization / Compensation Expectations / Role Alignment / Motivation & Availability）。中文段里的「全日制」「学信网」「社保公积金」在海外无对应概念或不可问，直译即踩线；页脚须保留免责声明。

### 模式 B：AI 自由发挥

- 6-8 题，每题结构：**问题 → 考察要点 → 设计理由**。
- 侧重：职业动机与规划一致性、稳定性与工作安排（出差/出勤约束）、薪酬期待合理性、行业与岗位认知、自我认知、文化适配。
- 同样围绕候选人经历定制，不套用通用题。

## 三、30 分钟时间分配表

### 业务面 30min（两种模式通用）

| 环节 | 时长 |
|---|---|
| 开场/优势展开（从最自豪的经历聊起） | 3' |
| 核心能力深挖（高光打法 + 情境前瞻） | 15' |
| 验证与风险（疑点中性进入，口径多已并入深挖） | 7' |
| 动机与吸引（双向：他要什么 + 岗位给什么） | 5' |

### HR面（不渲染时间表）

HR面 30min 按模板四段自然分配（身份诚信 5' / 薪资流水 7' / 岗位匹配 10' / 动机风险 8'），**产物不再输出 HR面时间表**——HR面导出时以「面试节奏要点卡」（开场铺垫/收尾 5 分钟/追问礼仪）收尾，观感更干净。四段时间仅作内部参考。

## 输出格式约定

业务面每题输出为结构化卡片（6 要素齐全，追问路径 3-4 条带技巧标签；高分锚定/红旗信号单条 ≤18 字）；HR面模板模式按四段输出；**时间分配输出为业务面 30min 表 + 面试节奏要点**（开场铺垫话术一句 / 收尾 5 分钟动作 / 追问礼仪一条，两场通用；HR面不输出时间表）。全部数据供 html-output 直接渲染。

## 分拆交付约定

业务面清单与 HR面清单**可独立导出**（模板内置「导出业务面 / 导出HR面 / 导出全部」三个按钮）：业务面导出内容=头部+匹配度与核心优势+待考察点+业务面教学卡+业务面时间表+节奏要点；HR面导出内容=头部+匹配度与核心优势+待考察点+HR面清单+节奏要点。交付时提示用户：导出业务面长图可直接单独发给业务面试官。
